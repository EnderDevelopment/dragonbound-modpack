# Dragonbound Minecraft Mod

Dragonbound is a Minecraft mod companion for a dragon-focused Minecraft mod pack on Minecraft 1.20.1 with Forge. It adds a Dragon Codex and Dragon Altar to support dragon-themed play alongside separately installed dragon mods; the dragon mods themselves are not included.

## Install

1. Install Java 17 and Minecraft Forge 1.20.1, using Forge 47.2.0 or a compatible Forge 47.x build.
2. Build the mod from its project files with `./gradlew build` on Linux or macOS, or `gradlew.bat build` on Windows.
3. Copy `build/libs/dragonbound-1.0.0.jar` into your Minecraft `mods` folder.
4. Launch Minecraft with the Forge 1.20.1 profile.

## Use

1. Start a world with Dragonbound installed.
2. Craft the Dragon Codex using a book, paper, and dragon breath. Hold it and use it to display brief information about dragon mods and the altar.
3. Craft the Dragon Altar using obsidian, a gold block, dragon breath, and an ender eye. Place it and interact with it to see its message.
4. To play with other dragon mods, install their separate Forge 1.20.1 files and any required dependencies. They are not bundled with Dragonbound.
